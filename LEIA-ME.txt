KIT v1.01-pre  (frontend/main.cpp  +  frontend/menu/*  )

O QUE MUDA
1. Diagnostico do USB: o boot.log passa a ter uma linha  "/mnt holds: ..."  com tudo que o PS4
   mostra dentro de /mnt. Se o seu HD/pen drive aparecer com outro nome (ex.: usb, ext0), me conte.
2. Profiler desligado por padrao (menos trabalho no jogo). Para ligar de novo: profile=on no settings.txt.
3. Nova opcao no settings.txt:  cpu_accuracy=auto | accurate | unsafe   (padrao: auto)
   "unsafe" deixa as contas de ponto flutuante mais rapidas e pode alterar o jogo (testar no MK8D).
4. Linha de versao do boot.log: "v1.01-pre".

COMO INSTALAR
- Copie a pasta frontend deste kit para C:\nxorbis\repo\frontend (substituindo main.cpp e menu\*).
- Compile como sempre:  source tools/env-build.sh && unset OO_PS4_TOOLCHAIN
                        cmake --build build-eden --target eden-ps4
                        bash package-eden.sh
- Se o compilador reclamar de "CpuAccuracy::Accurate" ou "Unsafe": me mande a mensagem
  (eu nao consegui conferir o codigo do Eden daqui).

VERSAO 01.01 (opcional, so quando for lancar)
  sed -i 's/"01.00"/"01.01"/g' package-eden.sh

NOVO (settings.txt de fabrica)
- Na primeira vez que o app abre e NAO existe /data/edenps4/settings.txt, ele cria um com a melhor
  configuracao de cores conhecida (swapview=a8s,a8uf,a2l / swapwrite=depth). Quem ja tem
  settings.txt continua com o seu. Para voltar ao padrao: apague o settings.txt e abra o app.
- O boot.log mostra "settings.txt did not exist: the default one was created" quando isso acontece.

NOVO (backup automatico dos saves - ideia vista no projeto ps4-switch-emu)
- Antes de cada jogo abrir, se os saves mudaram desde o ultimo backup, o app copia
  nand/user/save para /data/edenps4/save-backups/<numero>/save e guarda so os 3 ultimos.
- Se a pasta de saves passar de 256 MiB, o backup e pulado. O boot.log mostra "save backup: ...".
- Para restaurar: copie o conteudo de save-backups/<numero>/save de volta para nand/user/save.
- Se o compilador reclamar desta parte, me mande a mensagem (nao consegui compilar daqui).

NOVO (ideias vistas no ps4-switch-emu, feitas do nosso jeito)
1) Configuracao por jogo: crie a pasta /data/edenps4/settings/ (o app cria sozinho) e coloque ali um
   arquivo .txt com as mesmas linhas do settings.txt. Ele vale para o jogo cujo nome de arquivo contem
   o nome do .txt (sem diferenciar maiusculas). Pode usar o ID do jogo, ex.:
      settings/0100152000022000.txt     (para "Mario Kart 8 Deluxe [0100152000022000]...")
   Aplicado DEPOIS do settings.txt. O boot.log mostra "per-game settings: <arquivo>".
2) Cronometro de carregamento: o boot.log agora tem "load timer: ... first frames within X s" e
   "30 fps or more within X s" (contado a partir de escolher o jogo no menu). Enquanto nao chega a
   30 fps, a linha "status:" sai a cada 5 s (depois, a cada 10 s).
3) tools/analyze-boot.py: resume um boot.log (fases, tempos, fps, uso de CPU). No PC:
      python tools/analyze-boot.py boot.log
   (precisa do Python; e so leitura). Se quiser, me mande o boot.log que eu rodo por voce.
